Fixed Point Iteration - Question 1

Question: Use the Fixed Point Iteration Method to solve x = cos(x). Take the initial approximation x0 = 0.5, tolerance 10-4, and maximum 100 iterations. 
clc;
clear;

g = @(x) cos(x);

x0 = 0.5;
tol = 1e-4;
n = 100;

disp('Fixed Point Iteration Method');
disp('Iteration x');

for i = 1:n
    x1 = g(x0);
    disp([i, x1]);

    if abs(x1 - x0) < tol
        disp('Root = ');
        disp(x1);
        disp('Number of iterations = ');
        disp(i);
        break;
    end
    x0 = x1;
end

Lagrange Interpolation - Question 1

Question: Using Lagrange Interpolation, find the value of y at X = 2.5 from the data:
x: [1, 2, 3]
y: [1, 4, 9]
Write a MATLAB program in which the user enters the values of x, y, and X. 
clc;
clear;

n = input('Enter the value of n: ');
x = input('Enter x values: ');
y = input('Enter y values: ');
X = input('Enter the value of X: ');

P = 0;

for i = 1:n+1
    L = 1;
    for j = 1:n+1
        if j ~= i
            L = L * (X - x(j)) / (x(i) - x(j));
        end
    end
    P = P + y(i) * L;
end

disp('Interpolated value = ');
disp(P);

Newton's Method - Question 5 (Two Equations)

Question: Use Newton's method to solve the system:
x2 + y2 - 4 = 0
x - y = 0
Take x0 = 1, y0 = 1 and perform 5 iterations. 
clc;
clear;

x = 1;
y = 1;

for i = 1:5
    f1 = x^2 + y^2 - 4;
    f2 = x - y;
    
    J = [2*x 2*y;
         1   -1];
    
    F = [f1; f2];
    d = -(J\F);
    
    x = x + d(1);
    y = y + d(2);
end

disp('x = ');
disp(x);

disp('y = ');
disp(y);
